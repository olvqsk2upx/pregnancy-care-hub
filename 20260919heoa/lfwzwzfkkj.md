# 试管婴儿请假要多久？去外地做试管婴儿一般需要向单位请多久的假

> 更新时间：2026-09-19 (UTC+8)

试管婴儿请假要多久？去外地做试管婴儿一般需要向单位请多久的假，一起和来详细了解。

试管婴儿的流程一般在2-3个月左右，如果是取去外地做试管婴儿，在整个试管流程的过程中总共可能需要请半个月到一个月的假。试管整个周期包括术前检查、建档、定方案、降调、促排、取卵、移植等，在有些阶段需要本人到医院，对于时间比较紧张的上班族来说就需要请假了，整个试管流程下来差不多需要请假半个月到一月的时间。

从开始检查最后移植，去医院的次数最少可能要在十次以上，虽然不用天天请假， 但是但是常常请假是肯定的，特别是在促排阶段，还需要天天到医院监测卵泡，所以在职状态下做试管就会比较麻烦，到外地做试管需要请假的时间具体如下：

- 1. 进周前检查，一般建议女性先在月经第2、3天进行抽血检查（血常规、六项性激素等）及B超检查基础卵泡；AMH、染色体、肝肾功能、甲状腺功能、感染性指标等也可一起抽血，一般这些检查需要请假1天时间；
- 2. 建档，在所有结果出来后，医生会通知夫妻约定时间，携带双方身份证、结婚证一起到医院建档，这个步骤要夫妻双方同时在场，双方都需请假半天左右；
- 3. 降调，如果是长方案、超长方案等需要降调的话，在医生通知的时间，打一针降调针即可正常返回，到医生通知的时间返院复查，指标达到标准后即可促排。打降调当天女方请假约半天；
- 4. 促排阶段，这就是需要频繁返院的阶段了，需要根据医嘱复查激素、B超监测卵泡大小，一般在促排后期需要隔天或者当天返院，整个促排周期大概需要3-6次左右的半天时间；
- 5. 取卵，取卵时女方可请假1、2天，适当休息，如果取卵后出现腹水、胸水等情况，按医嘱返院进行点滴等治疗，按需请假；
- 6. 通知胚胎情况，一般取卵后3天，告知胚胎配对情况，如果是培养囊胚，则需要5-6天，如果暂时不移植，有的医院会通知夫妻双方到院签订冷冻协议，一般也需要半天时间左右；
- 7. 胚胎移植，移植需夫妻妻双方携带证件到场，过程只需几分钟，加上等待、排队时间，请假半天即可；
- 8. 在促排中后期、移植前期，可能需要集中请假一段时间（1-2周），可以考虑住在试管当地的旅店或是姐妹房，节约往返的各项时间、精力、金钱成本。
