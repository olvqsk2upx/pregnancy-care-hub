# 促排空腹抽血查激素四项主要是检查什么的？

> 更新时间：2026-09-19 (UTC+8)

女，36岁，生育过一次，大宝今年4岁，我和老公打算再要个二胎，备孕了3个多月都没怀上，检查发现有卵巢早衰的迹象，自然受孕困难，医生建议先进行促排卵治疗，目前是促排5天，医生让我明天早上空腹抽血查一下性激素四项，我想问下这个项目主要是查什么的？一定要做吗？ 
查看全部内容

促排空腹抽血查激素四项主要是检查孕酮、雌二醇、促卵泡生成素，以及促黄体生成素，然后参照促排四项激素对照表来判断促排卵治疗效果。孕酮是由卵巢分泌，可以促进子宫内膜转化，雌二醇主要由卵巢分泌，能够促进子宫内膜进入增殖期，促卵泡生成素是由腺垂体分泌的，主要功能是促进卵泡发育成熟以及促进雌激素分泌，促黄体生成素也是有腺垂体分泌的，能够促进排卵和黄体生成。

临床上激素四项是最常规的检查项目之一，尤其是对备孕的女性来说，这项检查必不可少，最好在月经第2-5天空腹抽血，然后结合检查结果考虑是否进行下一步操作。下面可以了解一下促排检查激素四项的意义：

- 1. 孕酮，属于孕激素中的一种，对于调节月经周期和维持妊娠有一定的作用，促排用药刺激孕酮分泌后，和雌二醇会诱发促黄体生成素高峰出现；
- 2. 雌二醇，由卵巢分泌，是雌激素的一种，能促进子宫内膜增殖，在没有排卵时这项数值不会出现周期性变化，所以不能作为有无排卵的参考指标；
- 3. 促卵泡生成素，由脑垂体分泌，其主要作用就是促进卵泡的成熟和发育；
- 4. 促黄体生成素，可以刺激卵巢分泌雌激素，促黄体生成素异常升高常见于多囊卵巢综合征患者。
促排用药过程中，除了需要检查激素四项之外，还需进行血常规、肝功能、肾功能、心电图等一系列检查，抽血检查要注意空腹，做心电图检查要保持心态稳定，避免影响到检查结果。
